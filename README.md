# Twiglles 2035

Четыре статических сайта для руководства Twiglles и стартовая страница со ссылками на них.

| Файл | Сайт |
|---|---|
| `strategy.html` | Twiglles Global 2035 — стратегия, экосистема, дорожная карта |
| `bets.html` | Ставки Twiglles 2035 — методика ставок Revolut для Twiglles |
| `marketing.html` | Маркетинг Twiglles 2027 — 42 темы карты маркетинга с примерами |
| `smart-rich.html` | Уроки Smart&Rich — что из эфиров женского бизнес-клуба взять в стратегию |

Сборка не нужна: каждый сайт — один HTML-файл, шрифт Benzin встроен, Montserrat подгружается с Google Fonts.

## Как выложить на GitHub Pages

1. Создайте на github.com новый публичный репозиторий, например `twiglles-2035`.
2. Загрузите в него содержимое этой папки:
   - через сайт: **Add file → Upload files**, перетащите все файлы, нажмите **Commit changes**;
   - или из командной строки:
     ```bash
     git init
     git add .
     git commit -m "Сайты Twiglles 2035"
     git branch -M main
     git remote add origin https://github.com/ВАШ-ЛОГИН/twiglles-2035.git
     git push -u origin main
     ```
3. В репозитории откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/twiglles-2035/`.

Файл `.nojekyll` отключает обработку Jekyll, чтобы GitHub отдавал файлы как есть. Не удаляйте его.

## Без GitHub

Откройте `index.html` двойным щелчком: всё работает локально. Можно также перетащить папку на app.netlify.com/drop.

## Важно

- Отметки в чек-листах хранятся только в браузере того, кто их поставил, и в репозиторий не попадают.
- На бесплатном тарифе GitHub Pages сайт из публичного репозитория виден всем, у кого есть ссылка. Если материалы внутренние, используйте приватный репозиторий на платном тарифе или другой закрытый хостинг.
